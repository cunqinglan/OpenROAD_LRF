TopologyChecker 快速参考
========================

启用检查
--------
arranger->enableTopologyCheck(true);
arranger->visitParallel(sta, local_sta, resizer, visitor);

违规类型
--------
1. FANIN_NOT_VISITED        - Fanin 未访问就访问当前节点
2. SIBLING_ORDER_VIOLATION  - Sibling 乱序访问  
3. CONCURRENT_MODIFICATION  - 并发修改同一节点 ⚠️

输出示例
--------
!!! TOPOLOGY VIOLATION !!!
Type: FANIN_NOT_VISITED
Vertex: _12345_
Thread: 140123456789000
Detail: Fanin _12340_ has not been visited yet

API
---
void enableTopologyCheck(bool enable);     // 启用/禁用
void printTopologyViolations() const;      // 打印违规

何时使用
--------
✓ 调试并发 segfault
✓ 验证任务调度正确性
✓ 检测数据竞争
✗ 生产环境（有性能开销）

典型工作流
----------
1. 发现 segfault in parallel_gate_sizing
2. arranger->enableTopologyCheck(true)
3. 重新运行，观察违规输出
4. 根据违规类型定位问题：
   - CONCURRENT_MODIFICATION → 调度逻辑bug
   - FANIN_NOT_VISITED → 依赖图或引用计数bug
   - SIBLING_ORDER_VIOLATION → visitor 需要加锁
